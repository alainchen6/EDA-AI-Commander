  1. Google 发布 Gemini 4 Neon

    Neon 面向复杂软件工程、知识工作和科学流程，定位在 Gemini 4 Carbon（长程难题）与 Hydrogen（日常快速）之间。模型 ID 为 gemini-4-neon；标准价为每百万 token 输入 3 美元、缓存输入 0.15 美元（官方称 95% 折扣）、输出 15 美元；上下文为 100 万 token，Cloud 文档写明这是输入与输出合计的统一上限（含 thinking 与工具调用）。思考档为 LOW / MEDIUM / HIGH（默认）/ XHIGH。官方称 xhigh 档在 Artificial Analysis Intelligence Index 上得 61 分、总榜第 3，Coding Agent Index 以 58.6 分排第 1，默认 High 档每任务成本比 Carbon 低 32%。今日起在 Gemini API（Google AI Studio 付费档）、Gemini for business、Antigravity（Pro/Ultra）和 Gemini 应用（Pro/Ultra）推出。API 只用隐式缓存（显式缓存不支持），并以 thinking_level 取代 thinking_budget。这会立刻影响选型、报价和默认模型。

  1. DeepMind 发布 Genie 4，并在 Project Genie 对 Ultra 用户开放

    Genie 4 是 DeepMind 新一代世界模型，首次对符合条件的 Google AI Ultra 用户在 Project Genie 中开放。可在探索中途用自然语言实时改场景，并首次提供与画面同步的实时原生音频（环境声与角色对白）。模型卡写明输出为实时 720p、最高 24 帧/秒，且带同步音频；系统基于 Gemini Omni Flash，并用 Gemini 做推理与实时转向。同日 Genie 3 也升级：单次生成从 60 秒延长到 3 分钟，并支持世界串联和以 360° 全景图作为种子。另有 Project Genie agent 与社区画廊，生成的视频和音频带 SynthID。这是新世界模型首发，但目前是 Ultra 订阅者的浏览器研究原型，不是通用开发者 API。

    Google DeepMind

  2. OpenAI 公布芯片设计评测，并与 Synopsys 合作训练 GPT-Synopsys

    官方给出已硅验证的结果：Jalapeño 向量单元标准单元面积约降 13%、矩阵单元约降 10%。与 AMD 合作，在已高度优化的旗舰 GPU IP 上相对基线最多提升 14% PPA，部分改动已进入近期流片，另有改动写入后续生产设计文件；下一代旗舰 CPU 的关键模块也有个位数百分比的 PPA 收益。评测用开源 PicoRV32 和 OpenTitan Ibex，在约 11.2 万 token 的可比预算下，GPT-6.2 Astra 在两个核心上平均分最高，优化现有 PicoRV32 时得分约是 GPT-6 Astra 的两倍。为把能力接到工程师现有流程，OpenAI 正与 Synopsys 合作训练 GPT-Synopsys，让模型按芯片工程师的方式使用 Synopsys EDA 工具。这是方法和评测更新，还不是可直接调用的公开芯片设计 API。

    OpenAI

  3. OpenAI 更新研究加速报告：代理已能独立完成近半数 2–4 小时研究任务

    这是该公司对内部编码代理如何加速 AI 研发的量化更新。3 月到 10 月，代理独立完成预估需 2–4 小时人工任务的成功率从 23% 升至 46%，4–8 小时任务从 13% 升至 35%；按任务类型并不均匀：监控训练运行为 79%，启动训练为 35%，编写推理与服务栈代码为 25%。按 API 标价，10 月研究员日均用量中位数为 2400 美元，90 分位为 2.3 万美元。安全与对齐的记录工作周在 1 月到 9 月增加 77%。官方把这份报告作为递归自我改进（RSI）指标的公开披露。

    OpenAI
