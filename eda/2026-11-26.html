  2. AgentDRC: Multi-Agent Algorithms for Spatially-Aware Automated DRC Correction

    补入（原发布 2026-11-24）。物理设计里残差 DRC 仍常要人工修，现有 LLM 智能体又容易被无关图形、原始坐标上的空间推理不足，以及扁平版图表示拖累。论文把迭代修 DRC 写成多智能体算法：按几何与非几何动作分流，用空间关系过滤无关图形，再检查方向、幅度和邻近冲突。作者称，在较难的违例上最高达到 30.4% 的 pass@1 和 55.7% 的 pass@5，pass@5 比最强基线高 13.8 个百分点，并计划在论文接收后开源代码和基准任务。这些数字来自论文自述，需用自己的规则和版图核实。

  3. RTLDetective: Agentic RTL Debugging through Dataflow Analysis and Simulation-Guided Fault Localization

    补入（原发布 2026-11-24）。RTL 功能错误会沿信号和模块边界传播，只看输出波形往往找不到根因；没有黄金参考时，中间信号的期望值也不清楚。论文提出多智能体框架：从 RTL 建信号依赖图，从失败波形提取信息；定位智能体预测中间信号的期望值，再通过有针对性的仿真干预沿依赖关系探测，缩小可疑逻辑；调试智能体结合静态分析、硬件设计原则和 RTL 缺陷模式知识库生成修补，并在迭代中复用缓存上下文以降低推断开销。作者在 MEIC 基准上称修复率为 86.1%，比最强基线高 13.9 个百分点，同时调用 LLM 的次数更少。这些数字来自论文自述，需自行核实。

  4. CPU-Eval: Evaluating Large Language Models for CPU Hardware Code Generation

    补入（原发布 2026-11-24）。近期 HDL 生成系统在 VerilogEval 上的通过率已超过 90%，继续用它很难分辨进展。作者给出 CPU-Eval：339 个生成题目，来自 6 款实际 CPU（含已流片系列），覆盖从小嵌入式核到可跑 Linux 的乱序核，语言包括 SystemVerilog、Chisel 和 SpinalHDL。每个题目让模型生成一个子模块，再嵌回原 CPU、跑测试程序并用轨迹比对定位功能错误。作者称，7 个最新模型在 CPU-Eval 上的平均 pass@1 比 VerilogEval v2 的 Spec-to-RTL 低 45.14 个百分点；源码行数更多的子模块，以及使用更小众 HDL 的 CPU，pass@1 也更低。这些数字来自论文自述，需自行核实。

  5. Translation Validation of SystemVerilog-to-SystemC RTL Conversion by Reading the Generated C++

    补入（原发布 2026-11-24）。越来越多 SystemC RTL 模型来自翻译器或语言模型，错模型通常仍能编译，也常常和 RTL 表面上一致；但 SystemVerilog 按位宽截断、C++ 按更宽整数运算，漏掉一次截断就可能只在接近上限的激励上暴露。作者开源了 SystemVerilog 到 SystemC 的转换器 svcc，并用 C++17/SystemC 的语义解读生成头文件，把未定义行为变成证明义务，再按同名寄存器对源网表做归纳等价证明。在 50 个作者自写设计上证明了 45 个，另 5 个被报告为超出模型；在变异实验中，17 个能编译且 SystemC 仿真已显示错误的变异均未被接受。对 16 个开源库中的 2,184 个模块，有 1,185 个转换在随机联合仿真中与 Verilator 一致，其中 600 个被该检查证明；同一批运行还发现了前端、svcc 和 Verilator 中的缺陷。

  1. Walk the Cycle: An Efficient Stochastic Solver for Periodic Thermal Analysis of 2.5D/3D ICs

    补入（原发布 2026-11-24）。2.5D/3D IC 在周期负载下会进入周期稳态，全场确定性求解偏贵，现有随机游走又不是为长期周期问题和含 TSV 的多尺度结构设计的。论文提出 CycleWalker：把周期稳态写成无需初温和预热的无限历史反向游走，但只估计周期先验的残差，并用俄罗斯轮盘缩短长路径且保持无偏；先验由粗网格傅里叶求解再加细网格平滑低成本构成，热图则按 TSV 阵列构造以限制跳跃率并保留各向异性导热。作者称，在同等精度下，相对瞬态随机游走求解器最高可加速 75.85 倍。这些数字来自论文自述，需用自己的结构和工具核实。
