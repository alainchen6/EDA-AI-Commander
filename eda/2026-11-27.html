P1 建议看

  1. 3D IC 寄生提取：四条平面 signoff 假设在混合键合堆叠上不再成立

    Siemens Digital Industries Software 的 Calibre 寄生提取团队指出，面向平面芯片的四条 signoff 习惯在混合键合和紧密堆叠的 3D IC 上不再成立：只在裸片级签核并不能代表装配后的耦合与负载；把整堆扁平化一次性提取也往往不可行；接口提取算出的耦合电容如果落在未暴露的内部或被切分的导体上，合并网表时会被丢掉；把一条沿键合面走线的耦合收成单点端口，也会掩盖分布式效应。文章给出的做法是模块化、装配感知的提取：各裸片单独提取，再只提取接口处的跨裸片耦合且不重复计算，并预先生成连接点，使内部网和分布耦合都能进入系统级网表，供时序、噪声和信号完整性分析使用。文中以 Calibre 3DStack 与 xACT3D 为例说明该流程，具体精度仍需用自己的堆叠和工具核实。

  2. DiversePlace: Diversity-Seeking Curriculum Reinforcement Learning for Macro Placement

    补入（原发布 2026-11-25；因 arXiv 收录滞后，昨日扫描未进入候选）。宏观布局必须在后续实施结果还测不准时就做决定，现有强化学习布局器多半只优化半周长线长（HPWL）这一不完美代理，容易收敛到单一模式，而 HPWL 最好的方案并不一定是后续拥塞或 PPA 最好的。DiversePlace 用带质量门控多样性奖励的课程 PPO，在有竞争力的 HPWL 区域内维持一组彼此有差异的候选，供后续阶段挑选。作者称，在 ISPD2005 的八个设计上，top-5/10/20 归档多样性均有提升，HPWL 全部更低或几乎持平，并且效率更好；代码已公开。这些数字来自论文自述，需用自己的设计和下游流程核实。

  3. Kolpona: An Agentic Framework with Gradient-Free Neuron Programming for RTL Generation

    补入（原发布 2026-11-25；因 arXiv 收录滞后，昨日扫描未进入候选）。开源权重的 RTL 生成模型通常要靠大规模已验证 Verilog 语料做微调。Kolpona 提出无需梯度训练的做法：用闭式的单神经元写入去掉在练习任务上发现的失败习惯，只有在新任务的 testbench 结果变好时才保留该修改；推理阶段再用带工具的智能体提出候选，并在没有黄金 testbench 或参考设计的条件下选出一个设计。作者称，在 Qwen3.5-4B 上，编辑 16 个神经元后，模型单独的 VerilogEval v2 pass@1 从 31.7% 升到 55.4%，完整框架达到 77.6%；在 Qwen3.8-27B 上，VerilogEval v2 从 73.1% 升到 94.9%，RTLLM v2.1 从 66.0% 升到 92.0%。这些数字来自论文自述，且近期已有工作指出 VerilogEval 区分度下降，需自行核实。

  1. NEVA: Natural-Language Co-Evolution and Validation of Microarchitectures

    补入（原发布 2026-11-25；因 arXiv 收录滞后，昨日扫描未进入候选）。已有用大模型演化微结构的方法，多半直接改架构仿真器里的 C++ 代码，模型和实现细节缠在一起，也缺少对硬件约束的显式校验。NEVA 先从已有论文抽取结构、状态和决策规则，再在自然语言规格层面共同演化多个部件，并对候选做分阶段校验后再生成仿真代码。作者称，在 Claude Opus 5.5 下，相对 Pythia–Mockingjay 基线，留出单核性能最高提升 4.8%；一次 EvoX 搜索评估 40 个候选，约 2.2 天、按 API 标价约 320 美元。多核结果与基线没有显著差异。这些数字来自论文自述，需自行核实。
